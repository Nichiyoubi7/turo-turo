# Turo Turo

Commission site for educational materials (modules, PPT decks, worksheets,
IMs, ILAW-format DLLs) — Elementary through College.

## Structure

```
client/     Nuxt 3 + Tailwind CSS frontend (built, working)
api/        Laravel + PostgreSQL backend (planned, not yet built)
```

Frontend and backend are kept separate on purpose — same convention as the
OBRA project.

## Frontend

See `client/README.md` for setup instructions and a full breakdown of the
components and data structure.
